# TECHNOLOGY STACK

## Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS
* PWA support

## Backend

* Python 3.12+
* FastAPI
* Pydantic
* SQLAlchemy 2.x
* Alembic
* PyMySQL

## Database

* MySQL 8
* InnoDB
* `utf8mb4`

## OCR

* PaddleOCR atau alternatif open-source.
* Provider OCR harus menggunakan pola adapter agar mudah diganti.

## Voice

* Web Speech API untuk prototipe.
* Evaluasi alternatif ASR (Automatic Speech Recognition) jika dukungan browser tidak memadai.

## Development Tools

* Visual Studio Code
* Git
* Node.js
* Python virtual environment
* Laragon atau MySQL lokal

## Catatan

> * Jangan mengunci versi *dependency* berdasarkan perkiraan. Catat versi aktual setelah memeriksa kompatibilitas.
> * Docker tidak wajib untuk MVP (*Minimum Viable Product*).
